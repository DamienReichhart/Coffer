Download the file for your platform from the [download page](/download/). Every release has
installers for **x64** and **ARM64** on all three platforms. 7zip-GUI also needs **7-Zip** itself —
see [Installing 7-Zip](/docs/installing-7zip/); the app tells you if it can’t find it.

<Tabs syncKey="os">
<TabItem label="Windows">

Windows 10 and 11 are supported, on x64 and ARM64.

**Installer (.msi) — recommended.** Double-click `7zip-GUI-<version>-windows-<arch>.msi` and follow
the steps. The app is added to the Start menu, can be removed from *Settings → Apps*, and updates
itself in place. Administrators can deploy it silently:

```powershell
msiexec /i 7zip-GUI-1.0.0-windows-x64.msi /qn
```

**Portable (.zip).** Unzip anywhere — a USB stick, your Downloads folder — and run
`7zip-gui.exe`. Nothing is installed; when an update is available the app replaces its own
executable.

:::note[SmartScreen]
Windows SmartScreen may warn about an app it doesn’t know yet. Choose **More info → Run anyway**.
You can [verify the download](/docs/reference/verifying/) first.
:::

</TabItem>
<TabItem label="macOS">

macOS on Apple silicon (`arm64`) and Intel (`x64`). Not sure? Apple menu → *About This Mac*: a
chip named “Apple M…” is Apple silicon.

<Steps>

1. Open `7zip-GUI-<version>-macos-<arch>.dmg`.
2. Drag **7zip-GUI** onto **Applications**.
3. Open it from Applications or Launchpad.

</Steps>

:::caution[“7zip-GUI is damaged” or “unidentified developer”]
Builds that are not notarized by Apple are blocked by Gatekeeper the first time. After
[verifying the download](/docs/reference/verifying/), remove the quarantine flag once:

```sh
xattr -dr com.apple.quarantine /Applications/7zip-GUI.app
```

or Control-click the app, choose **Open**, then **Open** again. Releases signed and notarized with
an Apple Developer ID open without this step.
:::

</TabItem>
<TabItem label="Linux">

x64 and ARM64. Pick the format your distribution uses:

**Debian, Ubuntu, Linux Mint, Pop!\_OS (.deb)**

```sh
sudo apt install ./7zip-GUI-1.0.0-linux-x64.deb
```

`apt` also installs 7-Zip if your distribution packages it.

**Fedora, RHEL, openSUSE (.rpm)**

```sh
sudo dnf install ./7zip-GUI-1.0.0-linux-x64.rpm
# or
sudo zypper install ./7zip-GUI-1.0.0-linux-x64.rpm
```

**Any distribution (AppImage)**

```sh
chmod +x 7zip-GUI-1.0.0-linux-x64.AppImage
./7zip-GUI-1.0.0-linux-x64.AppImage
```

If your system lacks FUSE 2, run it with `--appimage-extract-and-run`, or install `libfuse2`.

**Package repositories.** When the download page lists APT and DNF repositories, adding one keeps
7zip-GUI updated with the rest of your system.

</TabItem>
</Tabs>

## Uninstalling

- **Windows:** *Settings → Apps → Installed apps → 7zip-GUI → Uninstall* (MSI), or delete the folder
  (portable).
- **macOS:** move `7zip-GUI.app` from Applications to the Bin.
- **Linux:** `sudo apt remove 7zip-gui`, `sudo dnf remove 7zip-gui`, or delete the AppImage.

Your settings are kept; see [Settings](/docs/reference/settings/#where-settings-are-stored) to remove
them too. Uninstalling 7zip-GUI never touches 7-Zip.
