7zip-GUI lists an archive’s contents with 7-Zip’s technical listing (`7z l -slt`), so you see every
file and folder with its real sizes, dates and attributes — nothing is extracted to show it.

## Opening

Any of these opens an archive:

- **Open archive** on the welcome screen, or the open button in the toolbar.
- Dropping an archive onto the window (see [Drag and drop](/docs/guides/drag-and-drop/)).
- A recent archive from the welcome screen’s list.
- Your file manager’s *Open with → 7zip-GUI*, or `7zip-gui path/to/archive.7z` from a terminal
  (see [Command line](/docs/guides/command-line/)).

7zip-GUI opens every format your 7-Zip reads: 7z, ZIP, RAR, TAR, GZIP, BZIP2, XZ, ISO, DMG, CAB,
WIM and many more. For split archives, open the first volume (`.7z.001`, `.zip.001`, `.part1.rar`).

## Moving around

- **Double-click** a folder to enter it; the **breadcrumbs** above the list take you back to any
  parent, and **Up** goes one level up.
- **Click a column header** — Name, Size, Packed, Modified — to sort by it; click again to reverse.
  Folders always come first.
- **Search** filters the current folder by name as you type.
- **Click** a row to select it; select several to extract or delete just those.

The status bar shows how many items are in the folder, their total size and your selection.

## Archive properties

The properties panel shows what 7-Zip reports about the archive: its type, compression method,
whether it is solid, whether it is encrypted, its physical size, the number of files and folders,
and the overall compression ratio.

## Encrypted archives

- If only the **contents** are encrypted, the list opens normally and a lock marks encrypted files;
  you are asked for the password when you extract or test.
- If the **file names** are encrypted too (7z archives created with *Encrypt file names*), 7zip-GUI
  asks for the password before it can show anything.

A wrong password is reported as such, and you can try again. Passwords are kept only in memory for
as long as the archive is open.

## Changing an open archive

From the archive view you can also:

- **Add files** to it — they are added at the top level with the archive’s own format.
- **Delete** the selected entries (with confirmation; 7-Zip rewrites the archive).
- **Test** it (see [Testing archives](/docs/guides/testing/)).

Formats 7-Zip can only read (RAR, ISO, DMG…) can be browsed, extracted and tested, but not changed.
