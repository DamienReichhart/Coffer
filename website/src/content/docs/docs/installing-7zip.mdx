import { Tabs, TabItem } from '@astrojs/starlight/components';

Coffer never bundles 7-Zip: it drives the 7-Zip command-line program installed on your
computer. That keeps 7-Zip coming from its official source, under its own licence, and lets you
update it whenever you like. Any recent version works; **7-Zip 21 or newer** is recommended.

<Tabs syncKey="os">
<TabItem label="Windows">

With [winget](https://learn.microsoft.com/windows/package-manager/) (built into Windows 10 and 11):

```powershell
winget install 7zip.7zip
```

Or with Chocolatey or Scoop:

```powershell
choco install 7zip
scoop install 7zip
```

Or download the installer from [7-zip.org](https://www.7-zip.org/). Coffer finds 7-Zip in
`C:\Program Files\7-Zip`, through the registry, on your `PATH` and in Scoop’s shims.

</TabItem>
<TabItem label="macOS">

With [Homebrew](https://brew.sh):

```sh
brew install sevenzip
```

This installs `7zz`, 7-Zip’s own build for macOS, on Apple silicon and Intel. The older `p7zip`
formula (`7z`) also works but is no longer maintained.

Coffer looks in `/opt/homebrew/bin`, `/usr/local/bin` and MacPorts’ `/opt/local/bin`, so it
finds Homebrew’s copy even when the app is started from Finder.

</TabItem>
<TabItem label="Linux">

| Distribution | Command |
| --- | --- |
| Debian 12+, Ubuntu 22.04+ | `sudo apt install 7zip` |
| Older Debian and Ubuntu | `sudo apt install p7zip-full` |
| Fedora 39+ | `sudo dnf install 7zip` |
| Older Fedora, RHEL (EPEL) | `sudo dnf install p7zip p7zip-plugins` |
| Arch Linux, Manjaro | `sudo pacman -S 7zip` |
| openSUSE | `sudo zypper install 7zip` |
| Alpine | `sudo apk add 7zip` |

The `7zip` packages provide `7zz` (and often `7z`); `p7zip` provides `7z` and `7za`. Use `7zip`
when your distribution has it: p7zip is an old fork and lacks recent fixes.

:::note[RAR archives]
Some distributions build 7-Zip without RAR support for licensing reasons. If RAR archives don’t
open, install your distribution’s non-free RAR plugin (for example `p7zip-rar` on Debian) or
7-Zip’s official Linux build from 7-zip.org.
:::

</TabItem>
</Tabs>

## How Coffer finds 7-Zip

In this order:

1. The path you set in **Settings → 7-Zip → Executable**, if any.
2. `7zz`, `7z` and `7za` on your `PATH` (`7z.exe` and `7za.exe` on Windows).
3. Well-known install locations for your platform (above).

**Settings → 7-Zip** shows the executable in use and its version. After installing or updating
7-Zip, press **Detect again** — no restart needed.

## A portable or custom 7-Zip

Point **Settings → 7-Zip → Executable** at any `7zz`, `7z` or `7za` — for example 7-Zip’s
standalone console build from 7-zip.org, unpacked into your home folder. Coffer checks that it
runs and shows its version before using it.
